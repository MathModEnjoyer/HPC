# Matrix Maultiplication (CUDA)
В данной работе реализовано параллельное умножение матриц с использованием технологии CUDA. Программа генерирует случайные матрицы размером от 100x100 до 2000x2000 с элементами в диапазоне от -10.0 до 10.0, после чего выполняет их умножение последовательно на CPU и параллельно на GPU. Время работы GPU замеряется только для вычислительного ядра без учёта операций копирования памяти. Для каждого размера матриц проводится 12 итераций, результаты усредняются и выводятся в виде таблицы, содержащей размер матриц, время выполнения на CPU и GPU, достигнутое ускорение и статус корректности вычислений.

Для компиляции кода на GPU использовался компилятор NVIDIA CUDA compiler driver NVCC для CUDA 
версии 12.4
