# **Vector Addition (CUDA, C++)**
В данной работе реализовано параллельное сложение векторов с использованием технологии CUDA. Программа генерирует случайные векторы длиной от 1000 до 1 000 000 элементов с плавающей точкой в диапазоне от -10.0 до 10.0, после чего выполняет их сложение последовательно на CPU и параллельно на GPU. Время работы GPU замеряется только для вычислительного ядра без учёта операций копирования памяти. Для каждого размера векторов проводится 12 итераций, результаты усредняются и выводятся в виде таблицы, содержащей размер векторов, время выполнения на CPU и GPU, а также достигнутое ускорение.
